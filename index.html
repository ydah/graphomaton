From install to SVG in a few lines.

Add the gem, define the states and transitions, then save the format you need.

gem install graphomaton
Read the full documentation
quick_start.rb
require 'graphomaton'

machine = Graphomaton.new
machine.add_state('idle')
machine.add_state('done')
machine.set_initial('idle')
machine.add_final('done')
machine.add_transition('idle', 'done', 'finish')
machine.save_svg('diagram.svg')

Keep the logic in Ruby. Put the diagram everywhere.
